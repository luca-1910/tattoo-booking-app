# Tattoo Booking App

Single-artist tattoo booking platform built with Next.js 14,
Supabase, and Google Calendar integration.

## Branches

- `main`       → production
- `develop`    → staging
- `feature/*`  → one branch per feature session

## Getting started

1. Copy `.env.local.example` to `.env.local` and fill in values
2. Run: `npm install`
3. Run: `supabase link --project-ref <your-project-ref>`
4. Run: `npm run dev`
